A program that sums up the world's news of Monday 23 November 2026 in one image: COP31 ends with no deal in Antalya, a Russian strike kills 11 in Dymer, AI stocks slide, and a Russian warship sinks off Libya — drawn as a newspaper front page, "THE WORLD", by a Node 22 program with no network at run time.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.png` (1024x1024) and `out/dossier.json` (the facts and their sources). Run it twice and the PNG bytes are identical.
